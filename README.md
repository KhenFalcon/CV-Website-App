## Running Locally:
- Clone this repository
- Open repository in IDE (VS Code) or PowerShell terminal
- (in PowerShell terminal) enter `npm install`
- enter `npm run dev`
- output should contain a local hyperlink (ex: "http://localhost:3000")
- Ctrl + left-click on the link or copy-paste it into your browser

## Building for Production:
- run `npm run build` to create an optimized production build
- run `npm start` to start the production server

## Technology Stack:
- **React 19** - UI library
